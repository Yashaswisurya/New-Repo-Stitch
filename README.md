# Yashaswi Surya — Growth Marketing Portfolio

A static, responsive portfolio based on the Stitch “Obsidian & Catalyst Editorial” direction.

## Preview / deployment
This repository is configured for GitHub Pages using GitHub Actions. Once the workflow completes and Pages is enabled to use **GitHub Actions**, the site should be available at:

https://yashaswisurya.github.io/New-Repo-Stitch/

## Local preview
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Notes before public launch
- The four headline metrics are the established results currently included; confirm supporting dates/evidence before expanding claims.
- Contact email, LinkedIn, and resume download are intentionally not fabricated. Replace the relevant placeholder in `index.html` when final details are provided.
- Google Fonts is an external dependency; system font fallback is included.
- This is a static site and requires no backend, API keys, or build step.
